=====================================
 ReadyQ 백엔드 - AI 면접 테스트 방법
=====================================

서버 주소: http://localhost:8080

테스트 도구: Postman 권장 (영상 파일 업로드 지원)
모든 면접 API는 JWT 토큰이 필요함 → 먼저 로그인 후 token 발급받기.

헤더 공통 설정:
  Authorization: Bearer {로그인에서 받은 토큰}

=====================================
 사전 준비
=====================================

1. 서버 실행
   Windows: gradlew.bat bootRun
   Mac/Linux: ./gradlew bootRun

2. 로그인으로 JWT 토큰 발급
   POST http://localhost:8080/api/auth/login
   Content-Type: application/json
   {
     "username": "testuser",
     "password": "test1234!"
   }
   → 응답의 "token" 값을 복사해두기

3. .env 파일에 Gemini API 키 설정 확인
   GEMINI_API_KEY=AIzaSyCKb46ZMh2bu4QCef-isiPoQvkDj1Pu79c

4. 테스트용 짧은 영상 파일 준비 (mp4 권장, 1분 이하)

=====================================
 STEP 1. 면접 시작
=====================================

POST http://localhost:8080/api/interview/start
Authorization: Bearer {토큰}
Content-Type: application/json

{
  "interviewerType": "FRIENDLY",
  "coverLetter": "저는 3년간 Spring Boot 백엔드 개발자로 근무하며 MSA 전환 프로젝트를 주도했습니다. 협업과 문제 해결을 중요시하며 꾸준히 성장하고 있습니다.",
  "targetCompany": "카카오",
  "targetJob": "백엔드 개발자"
}

interviewerType 선택지:
  FRIENDLY  - 친절한 면접관
  PRESSURE  - 압박형 면접관
  LOGIC     - 논리 검증형 면접관
  DEFAULT   - 기본형 면접관

→ 성공 응답:
{
  "sessionId": "abc123xyz",
  "periodNum": 1,
  "question": "간단한 자기소개와 지원 동기를 말씀해 주세요.",
  "interviewerType": "FRIENDLY",
  "message": "1교시를 시작합니다!"
}

※ sessionId와 question을 복사해두기. 이후 요청에 사용.

=====================================
 STEP 2. 1교시 영상 제출
=====================================

POST http://localhost:8080/api/interview/{sessionId}/period/1/submit
Authorization: Bearer {토큰}
Content-Type: multipart/form-data

form-data:
  key: video
  type: File
  value: (테스트용 영상 파일 선택)

예) Postman에서:
  - Body 탭 → form-data 선택
  - Key: video / Type: File / Value: 영상 파일 선택

→ 성공 응답 (Gemini 처리 완료 후 수신, 수십 초 소요될 수 있음):
{
  "sessionId": "abc123xyz",
  "completedPeriodNum": 1,
  "periodFeedbackSummary": {
    "overallScore": 72,
    "summaryFeedback": "전반적으로 논리적인 답변이었으나 말하기 속도가 다소 빠른 편입니다."
  },
  "canContinue": true,
  "message": "쉬는 시간입니다! 다음을 선택하세요."
}

※ 이 단계에서 내부적으로 꼬리질문 5개도 함께 생성되어 DB에 저장됨.

=====================================
 자주 발생하는 오류
=====================================

400 Bad Request
  - choiceType이 FOLLOW_UP인데 selectedQuestion이 없는 경우
  - sessionId에 해당하는 세션이 없는 경우

403 Forbidden
  - JWT 토큰 없거나 만료됨
  - 다른 유저의 세션에 접근하려는 경우

409 Conflict
  - complete 호출했는데 제출된 영상이 없는 경우
  - 이미 COMPLETED된 세션에서 잘못된 작업 요청

500 Server Error
  - Gemini API 키가 잘못된 경우
  - 영상 파일 저장 실패
  - 서버 콘솔 로그 확인 권장

=====================================
 Postman 사용 팁
=====================================

1. Collection 생성 후 Collection Variable로 관리 권장:
   - baseUrl: http://localhost:8080
   - token: 로그인 후 발급받은 JWT
   - sessionId: 면접 시작 후 반환된 sessionId

2. 영상 파일 업로드 (STEP 2):
   Body → form-data → Key에 "video" 입력 → Type을 File로 변경 → 파일 선택

3. 응답 시간이 길 수 있음 (Gemini 처리 시간):
   Postman 타임아웃 설정을 넉넉히 (90초 이상) 설정 권장
   Settings → General → Request timeout

=====================================
 전체 테스트 흐름 요약
=====================================

로그인 → 토큰 획득
  ↓
/start → sessionId + 1교시 질문 획득
  ↓
/period/1/submit (영상 업로드) → 피드백 요약 수신
  ↓
/period/1/options → 꼬리질문 5개 + 선택지 수신
  ↓
/period/1/next (FOLLOW_UP 또는 NEW_QUESTION) → 2교시 질문 수신
  ↓
/period/2/submit (영상 업로드) → 피드백 요약 수신
  ↓
(원하는 만큼 반복)
  ↓
/complete → 최종 피드백 수신
